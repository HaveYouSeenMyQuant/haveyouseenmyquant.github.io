A loop of string has one fixed length. Pull it into a long thin shape and it encloses very little. Pull the same string wider and the space inside changes fast, even though the outside length has not changed.

That is the trap: perimeter feels like it should tell you the size of the field. It mostly tells you how much boundary you bought. The shape decides how efficiently that boundary turns into space.

The video stops before the reveal: among the shapes shown, which one holds the most, and how much more does it hold than the square made from the same string?
