One block, three holes

puzzlesposted 20 Aug 2026

A board has three holes -- a circle, a square, a triangle. Could ONE block fit all three?

To fill each hole you would normally grab a different peg -- round, square, triangular. The rule here: one rigid block must pass snugly through every one of the three holes.

So is a single block for all three holes impossible -- or is there a shape that does it? The answer is a real object you can hold.
