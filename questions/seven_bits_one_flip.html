Seven bits, one flips, and the block says which

information_theoryposted 2 Aug 2026

Seven bits go down a wire, one of them flips, and the message can still tell you exactly which one.

No resend. No second copy to compare against. The receiver has never seen what was actually sent — and it can still point straight at the broken bit and fix it.

Here is the whole trick, and it fits in a picture. Draw three overlapping circles over the seven positions. Three circles carve the plane into exactly seven regions, so every position gets its own region and therefore its own combination of circles. Before the block leaves, three of the seven bits are set so that every circle holds an even number of ones.

Flip one bit and every circle it lives in goes odd. The circles that go odd overlap in exactly one place. That place is the broken bit.

In the video, two circles have gone odd and one is still even. That is enough to name the position, and I stop there.

So: which of the seven broke?

The honest limit, which almost nobody mentions: two flips break it, and not gracefully. The decoder does not shrug — it confidently blames a third, innocent bit and hands back a wrong message with no complaint. All 336 double-flip cases come out wrong. That is what a minimum distance of 3 buys you: one error findable, two errors indistinguishable.

This is Hamming's code from 1950, and a version of it is running in the memory of the machine you are reading this on.
