Diffusion models: noise walks back into a shape

ml_fundamentalsposted 5 Aug 2026

Static can walk back into a star.

The setup is a clean dot star. The forward process is boring on purpose: add a little noise, then add more, until the shape is visually gone.

The reverse process is the interesting part. The model is not asked to draw the whole object in one jump. It is asked for one tiny correction: make the current cloud slightly less noisy than it was a moment ago.

Repeat that small correction enough times and the cloud starts to carry structure again. That is the core trick behind diffusion models: many small denoising moves can behave like generation.

The withheld question is the new starting noise.
